# Configs

Experiment configuration files will live here.

- `probe_templates.yml` provides example probe prompt templates.
- `counter_example.yml` provides a reference counter task config.
- `accumulator_example.yml` provides a reference accumulator task config.
- `hidden_profile_example.yml` provides a reference hidden-profile task config.
- `hidden_profile_demo.yml` provides a 2-agent OpenAI demo config.
- `shapefactory_example.yml` provides a reference ShapeFactory-style task config.
- `daytrader_example.yml` provides a reference DayTrader-style task config.
- `maptask_example.yml` provides a reference MapTask-style task config.
